1. 今回前進した roadmap target

Layer 7: (SL_n) Borel subgroups と conjugacy が完成

PR #10920, f5ac66f は、前日に入った upper-triangular (SL_n) subgroup scheme と Lie--Kolchin triangularization を使い、

\[oxed{ ext{Borel subgroups of }SL_n ext{ are conjugate}}\]

を arbitrary rank で formalize しました。

これにより type (A) の classical worked exampleでは、maximal torus conjugacyだけでなく Borel conjugacyも scheme-theoretically揃いました。一般 reductive group の Borel conjugacyは依然 open です。

Layer 9: tripled (D_4) carrier の complete reducibility と (R_u=1)

PR #10834, a023db1 は tripled (D_4) carrier の standard representation を completely reducible とし、generated carrier の unipotent radical を trivial にしました。

carrier の smoothness / connectedness / root-generation は既に main にあったため、reductivity recognition の主要 ingredients がさらに揃いました。

Layer 9: type (B) spin carrier の simple standard comodule と (R_u=1)

PR #10757, 7c19b04 は full-weight type (B) spin carrier の standard comodule を simple とし、unipotent radical を trivial にしました。

前日までに smoothness / connectedness / root-generation が入っていたので、type (B) carrier も reductivity endpoint にかなり近づきました。

Layer 9: short-root (G_2), characteristic (3) の (R_u=1)

PR #10952, 3d22f23 は characteristic (3) の generated short-root (G_2) subgroup の unipotent radicalを trivial にしました。

prime-field carrier の smoothness / connectedness / root-generation と合わせ、special-isogeny carrier 自身の reductivity recognitionへ進んでいます。

Layer 9: doubled (E_6) carrier の (R_u=1)

PR #11023, 71fecfd は reduced doubled (E_6) carrier の unipotent radical を trivial にしました。

PR #10921, a32fcec は doubled (E_6) representation が2つの minuscule summands を保存することを formalize し、complete-reducibility routeの基盤を整えました。

Layer 9: type (D) spin representation の complete reducibility

type (D) spin carrier について representation-theoretic structure が連続して入りました。

  • #10911, a056cdb: two half-spin summands の保存。
  • #11037, 0f7b94a: signed simple-root moves。
  • #11053, 66d3072: torus weight lines の抽出。
  • #11091, 808d68b: standard spin comodule の complete reducibility。

これにより type (D) carrier の normal-unipotent eliminationに必要な representation input が揃いました。

Layer 9: prime-field (F_4) carrier の smoothness + simple comodule

PR #11146, c592b9b は characteristic (2) の prime-field short-root (F_4) carrier の smoothness を証明。

PR #11202, 723910b は 26-dimensional short-root comodule の simplicity を証明しました。

PR #11124, eca66ca は invariant weight components を抽出し、この simplicity proof と special-isogeny representation analysis の基盤を供給します。

Layer 3: dominant homomorphism の faithful-flatness route

PR #11197, 0874424 は dominant homomorphism に対する generic freeness / faithful-flatness machinery を構築しました。normal quotient representability と image/quotient comparisonの一般化に直接関係します。

Representation infrastructure: exterior powers and stabilizers

  • #11061, 5a91a27: arbitrary subspace と top exterior line stabilizer の同定。
  • #11081, 5f597f6: exterior-power comodules と point actions。
  • #11110, cff5837: square-zero divided-power preservation を sets に一般化。

これらは parabolic / stabilizer constructions と exceptional carrier representationを支える reusable API です。

2. 完成した endpoint

  2. tripled (D_4), type (B), short-root (G_2), doubled (E_6) で (R_u=1) への大幅な進展。
  3. type (D) spin standard comodule の complete reducibility。
  4. prime-field (F_4) carrier の smoothness + simple 26-dimensional comodule。
