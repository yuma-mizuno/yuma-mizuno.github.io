Layer 7: (Sp_{2m}) の Weyl group comparison が完成

PR #10353, 34b4949 は paired diagonal torus (Tsubset Sp_{2m}) の rational-point normalizer quotientを計算し、

\[N(T)(k)/T(k)simeq operatorname{Sym}(mathrm{Bool})wr S_m simeq W(C_m)\]

と同定しました。long-root representatives は sign change、short-root representatives は coordinate transposition に対応します。

これは (Sp) worked example の actual normalizer quotient と abstract root-datum Weyl group の bridge の completion です。scheme-theoretic normalizer quotient の representability theoremではありません。
