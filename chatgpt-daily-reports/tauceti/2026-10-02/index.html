1. 今回前進した roadmap target

Layer 6: Cartier theorem が完成

PR #10478, ac256cf は characteristic zero の finite-type affine group schemes に対する Cartier theorem を formalize し、

\[oxed{ operatorname{char}k=0,quad G/k ext{ finite type} Longrightarrow G ext{ smooth} }\]

を証明しました。coordinate Hopf algebra の reducedness も帰結します。

これは Layer 6 の characteristic-zero

\[ ext{reductive}iff ext{linearly reductive}\]

において、smoothness を別仮定として持ち回る必要をなくす重要な completion です。

Layer 6: (PGL_n) を matrix algebra の automorphism group scheme として構成

PR #10542, 6c59e2d は

\[PGL_nsimeq operatorname{Aut}_{mathrm{alg}}(M_n)\]

を closed subgroup scheme of (GL_{n^2}) として構成しました。さらに conjugation map

\[GL_nlongrightarrow PGL_n\]

を group-scheme morphism として作り、scheme-theoretic kernel が center と一致すること、field-valued points では Skolem--Noether により surjective であることを証明しています。

したがって (G/Z(G)) の concrete worked example に必要な candidate adjoint group scheme と quotient map が実体化しました。残るのは faithful flatness / fppf quotient representability を介した

\[GL_n/Z(GL_n)simeq PGL_n\]

の scheme-level quotient identification です。

Layer 7: (SL_n) の upper-triangular subgroup scheme と solvable subgroup の triangularization

PR #10763, 15cd185 は任意 rank の (SL_n) に standard upper-triangular closed subgroup scheme を構成しました。

さらに algebraically closed field 上の reduced connected solvable closed subgroup (Hsubset SL_n) が rational (SL_n)-point により upper-triangular subgroupへ conjugate されることを証明しました。これは (SL_n) Borel conjugacyへ直結する Lie--Kolchin step です。

Layer 9: reductive group schemes over a base と chosen split maximal torus

PR #10778, 16a66a1 は、commutative base ring 上の reductive affine group scheme を

  • smooth,
  • geometric fibres connected reductive,

として定義し、さらに chosen split maximal torus を data として持つ interface を導入しました。

(SL_n) とその標準 diagonal torus が arbitrary commutative base ring 上の worked example になっています。これは Layer 9 の「split reductive group schemes over (mathbf Z)」を formal に語るための基盤そのものです。

Layer 9: integral Kostant toral closures の flatness

PR #10758, 2a26d21 は integral Kostant toral closures の flatness を証明しました。

explicit carrier を (mathbf Z) 上の split reductive group scheme として認識するには smoothness と合わせて flatness / good base change が必要なので、Layer 9 の arithmetic carrier recognition に直接効く結果です。

Layer 9: root-generated carriers が classical / spin types へ拡大

  • #10456, f7573d2: standard type (C) symplectic carrier が root-generated。
  • #10580, 234a8f9: type (B) spin carrier が全 rank で root-generated。
  • #10651, 54a1cdc: standard type (A) carrier が root-generated。
  • #10562, 78848e3: generated Geck subgroup が smooth + connected。

この結果、root-generated closed subgroup scheme と explicit toral carrier の equality は classical / exceptional の複数 branches で標準的な interface になり始めています。

Layer 9: diagram symmetry / pinning

PR #10528, b2013ef と PR #10535, 1ad22e9 は、explicit carriers の graph automorphisms / diagram symmetries を numbered root subgroups による pinning と整合させました。

これは twisted finite Lie-type groups の Steinberg maps へ downstream する一方、core roadmap では pinned carrier の symmetry interface を完成側へ進めるものです。

Layer 9: (E_6) unipotent radical elimination

PR #10699, ad7ef48 は (E_6) minuscule carrier の unipotent radical を trivial にしました。既存の faithful/semisimple representation と smooth/connected geometryを結合する reductivity route の主要部分です。

Layer 7 / representation infrastructure: subgroup stabilizers

PR #10463, fdcac87 と PR #10428, c33f45d は subspace / top exterior line stabilizers を group-scheme として構成し、closed subgroups を representation-theoretic stabilizer として実現しました。Borel/parabolic constructions と characteristic-zero group/Lie stability comparisonの共通 infrastructureです。

Layer 7/9: spin weight Weyl orbits

  • #10601, 15609b3: type (B) spin weights が simple reflections の単一 orbit。
  • #10646, 93316f8: type (D) spin basis の simple reflections と2つの Weyl orbits。

これは spin representation の irreducibility / root datum recognition に使う combinatorial input です。

Layer 3: coinvariant quotient object

PR #9979, 75c143e は normal subgroup quotient の coordinate candidate として coinvariant Hopf algebra を package しました。前日の fppf quotient exactnessと合わせ、general normal quotient representability の core algebraic object が明示されました。

Layer 9: chosen split maximal torus の base change

PR #10811, 8f6d4af は chosen split maximal torus data の arbitrary base change compatibility を formalizeしました。
