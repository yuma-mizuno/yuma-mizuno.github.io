1. 今回前進した roadmap target

Layer 4: torus と Galois lattice の dictionary が cocharacter 側まで完成

PR #9196, 5087d6f は、perfect field 上の torus に対して character lattice と cocharacter lattice の双対性を formalize し、既存の character classification を cocharacter functor へ移しました。これにより Layer 4 の torus lattice dictionary について、split/non-split torus の character/cocharacter pairing と分類が一つの体系になりました。

残る主な gap は imperfect field への拡張です。

Layer 6: central isogeny の descent が完成

PR #9183, 2b90552 は、faithfully flat base change が isogeny を保存・反映し、field extension が central isogeny を保存・反映することを証明しました。kernel Hopf ideal の scalar extension compatibilityも入り、非既約な scheme-theoretic kernel を含めて centrality を追跡できます。

これは Layer 6 の simply connected / adjoint forms を algebraic closure 上で比較するための基盤です。

Layer 7: (SL_{n+1}) の標準 BN-pair / Tits system

PR #10091, c12a0da は、Tits system の pullback construction を一般化し、それを (SL_{n+1}(k) o GL_{n+1}(k)) に適用して標準 Tits system を構成しました。

したがって (SL_{n+1}(k)) に対しても既存の Bruhat cell / exchange condition / Weyl group machinery を利用できます。一般 split reductive group の BN-pair はまだ未完成です。

Layer 6: comodule representation の微分

PR #9227, 60bdcaf は rational comodule representation を tangent Lie algebra の representation へ微分する一般 construction を追加しました。Layer 6 の characteristic-zero

\[ ext{reductive}Longrightarrow ext{linearly reductive}\]

に必要な group representation と Lie algebra representation の bridge です。

Layer 9: explicit carriers の root-generated scheme identification

この期間には carrier generation が大きく進みました。

  • #10185, bd0e543: full-weight type (B) / (D) spin carriers が positive/negative simple-root subgroups だけで scheme-theoretically generated されることを証明。
  • #10115, 3c54396: (E_7) minuscule carrier について同じ root-generated closed subgroup scheme との同一視を完成。
  • #9955, 11420e5: (E_7) simple-root commutation relations を追加。

これらは以前の pointwise な「weight torus は elementary subgroup に入る」から、defining Hopf ideal の equality を使う scheme-level generation へ進んだ点が重要です。

Layer 9: generated carrier の smoothness / connectedness

explicit carrier を reductive group scheme と認識するための geometric input も進みました。

  • #9875, 163ce80: doubled (E_6) generated subgroup の connectedness。
  • #9866, 6e3d328: generated (F_4) subgroup の connectedness。
  • #9939, f619834: generated (E_7) minuscule subgroup の connectedness。
  • #9960, 1449cec: generated type (D_n) spin subgroup の smoothness + connectedness。
  • #10043, 165a962: generated type (B_{n+1}) spin subgroup の smoothness + connectedness。
  • #9988, ae9c96c: generated (E_6) minuscule subgroup の smoothness + connectedness。

Layer 7: rank-one Borel conjugacy

PR #9849, 877ad3a で (SL_2) の Borel subgroups の conjugacy が formalize されました。一般 rank の (SL_n) / 一般 reductive group の Borel conjugacy はまだ後続です。

Layer 4 / 6: finite diagonalizable kernels

PR #9187, e4fbcd0 は finite diagonalizable kernel の connectedness を character-group 側で特徴づけました。central isogeny と multiplicative-type kernel の解析に直接使う input です。

2. 完成した endpoint

今回の明確な completion は次の通りです。

  1. perfect field 上の torus cocharacter-lattice classification (#9196)。
  2. central isogeny の field-extension descent / reflection (#9183)。
  3. (SL_{n+1}) の標準 Tits system (#10091)。
  4. type (B/D) spin carriers と (E_7) carrier の root-generated group scheme identification (#10185, #10115)。
  5. 複数 explicit carrier で smoothness / connectedness package が完成。

3. roadmap を支える reusable infrastructure

#9227 の comodule differential は characteristic-zero reductive (Rightarrow) linearly reductive のための共通 bridgeです。#10091 の Tits-system pullback は (SL) 以外の subgroupにも再利用可能です。#9183 の faithfully-flat descent API は central isogeny / nonsplit forms 全般で使えます。

5. 現在の open gaps / blockers

  • Layer 4: torus lattice classification の imperfect-field extension。
  • Layer 6: characteristic zero の ( ext{reductive}Rightarrow ext{linearly reductive})。#9227 により differential bridge は完成したが、reductive Lie algebra の complete reducibility と group-stable / Lie-stable comparison が残る。
  • Layer 7: Borel conjugacy は (SL_2) のみ。一般 (SL_n) / classical groups / general reductive group が残る。
  • Layer 9: root-generated equality は (B/D/E_7) で scheme-level に到達したが、smoothness・reductivity・root datum・uniform pinned Chevalley-Demazure groupとの identification が次の共通 frontier。
