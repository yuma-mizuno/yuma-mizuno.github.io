1. 今回前進した roadmap target

Layer 9: short-root (F_4/mathbf F_2) carrier が reductive に

PR #11435, 0d480a7 は characteristic (2) の prime-field short-root (F_4) carrier が reductive であることを証明しました。

前日に smoothness と simple faithful 26-dimensional comodule が揃っていたため、normal smooth unipotent subgroup を消して

\[R_u(G)=1\]

を得る standard representation-theoretic route が閉じました。

これで short-root (F_4/mathbf F_2) carrier は、special isogeny を載せる 実際の reductive affine group として扱える段階に入りました。

Layer 9: prime-field (G_2) carrier の root generators が closed copies of (mathbb G_a)

PR #11543, 34b7a9a は characteristic (3) の prime-field short-root (G_2) carrier の numbered simple-root generators が scheme-theoretically closed additive subgroupsであることを package しました。

carrier の root-generated equality と special-isogeny equationsを、pointwise formula だけでなく genuine closed root subgroup scheme として扱うための missing bridgeです。

Layer 3: smooth affine group image が fppf quotient を represent

PR #11503, 3e40c82 は smooth finite-type affine group の scheme-theoretic imageを fppf quotient と同定する representability theoremを追加しました。

前日までの kernel/cokernel exactness、dominant/faithfully-flat machineryを消費し、

\[G/ker(f)simeq operatorname{im}(f)\]

を fppf quotient のレベルで実現する重要な case です。

Layer 3: normal coinvariants の finite generation

PR #11549, bbb7d34 は normal subgroup quotient の coordinate candidate である coinvariant algebra の finite generationを証明しました。

これは general normal quotient representability に必要な Noetherian / finite-type inputです。

Layer 4 / 6: multiplicative-type homomorphism の kernel 計算

PR #11530, 0522477 は multiplicative-type groups 間の morphism の scheme-theoretic kernel を character / lattice data から計算する API を整備しました。

central isogeny kernels、finite diagonalizable kernels、torus/Galois-lattice correspondenceに直接使う infrastructureです。

Layer 7: normalizer points による torus weight transport

PR #11563, f44a5a6 は torus を normalize する rational point が representation の torus weight spaces をどのように permutationするかを formalize しました。

これは Weyl group / normalizer action と representation weights を接続する Layer 7 infrastructureです。
