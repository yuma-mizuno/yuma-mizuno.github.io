1. 今回前進した roadmap target

Layer 3: fppf homogeneous quotient が一般形で構成

PR #11556, b3028e2 は affine group と closed subgroup に対する fppf homogeneous quotient を構成しました。

これは normal subgroup quotientだけでなく (G/H) 型の homogeneous space を fppf sheafとして扱う一般 interfaceです。Borel/parabolic quotientsや flag varieties への直接の入口になります。

Layer 3: normal quotient の exact kernel descent

PR #11948, e03f8ee は normal affine quotient の exact kernel propertyを base change / descent と結合しました。

normal subgroup quotient の representability theoremを最終的に short exact sequence

\[1 o N o G o G/N o1\]

へ昇格するための重要な compatibilityです。

Layer 6: comodule invariants の exactness

PR #11568, b3e3879 は comodule invariants functor の exactnessを証明しました。

これは linearly reductive groups の categorical characterizationに直接つながります。Layer 6 の

\[ ext{reductive}leftrightarrow ext{linearly reductive}\]

と Reynolds-operator / invariants-exactness interfaceを整理するための substantive representation-theoretic inputです。

Layer 9: short-root (G_2/mathbf F_3) carrier が reductive に

PR #11527, ff0a2a3 は characteristic (3) の prime-field short-root (G_2) carrier が reductive であることを証明しました。

smoothness、connectedness、(R_u=1)、root-generationが既に揃っていたので、special-isogeny carrier が genuine reductive group scheme として確立しました。

これで (G_2/mathbf F_3) と (F_4/mathbf F_2) の双方が reductive carrier になり、exceptional special-isogeny theoryの geometric foundationが揃いました。

Layer 7: affine group schemes over a ring の Borel subgroup

PR #11737, 104d0fa は commutative base ring 上の affine group scheme に対して Borel subgroup data を定義しました。

field 上の maximal connected solvable subgroupという classical notionを、geometric fibres と base-change-compatible dataを使う ring-level interfaceに移しています。Layer 9 の split reductive group scheme/pinning data に Borel を含めるための必要な over-base structureです。

Layer 7 / 9: matrix root subgroups を closed (mathbb G_a) として実現

PR #11750, 28b2fc9 は matrix root subgroup maps を scheme-theoretic closed copies of the additive group として一般に package しました。

pinning に必要な

\[x_alpha:mathbb G_ahookrightarrow G\]

を単なる point formula でなく closed group-scheme morphismとして扱う共通 APIです。

Layer 7: normalizer による character / weight action

PR #11590, 76a2305 は torus normalizer の character group 上の actionを構成。

PR #11627, 4c0ff0b はこの action の image が finite であることを証明しました。

PR #11798, 13c2e4b は normal subgroup の weight spaces が ambient action により permutationされる一般 theoremを追加しました。

Weyl groupを (N_G(T)/T) から character-lattice actionへ接続する abstract infrastructureが揃いつつあります。

Layer 7/9: (SL_n) の adjoint root spaces と root subgroup differentials

この期間には (SL_n) の concrete root geometry が一気に繋がりました。

  • #11817, 2d829fa: integral adjoint root lines。
  • #11792, a72cd0a: special-linear root subgroup differentials。
  • #11872, 289bdab: integral adjoint comodule root spaces。
  • #11931, 3479f1a: root differential と adjoint root space の同定。
  • #11854, 23d8dc3: Chevalley line の subgroup character。

これにより type (A) では

\[x_alpha quadstackrel{d}{longmapsto}quad X_alphainmathfrak g_alpha\]

が integral/scheme/representation levelsで直接接続されました。

Layer 7: (SL_n) Borel の Lie algebra と positive root containment

PR #11833, db43772 は standard (SL_n) Borel の Lie algebraを upper-triangular trace-zero matrices と同定しました。

PR #11958, f652747 は positive root subgroups が standard Borelを通って factorすることを証明しました。

したがって (SL_n) の

\[(T,B,{U_alpha}_{alpha>0})\]

という standard pinning/Borel configurationが scheme-level にかなり近づきました。

Layer 2 / 6: smooth cotangent module の finite projectivity

PR #11802, a7ff68e は smooth affine group の augmentation cotangent moduleを finite projective としました。

Lie algebra bundle / dimension / differential machineryを ring base 上で扱うための重要な Layer 2 infrastructureです。

Representation infrastructure

PR #11883, dd3cd53 は linear Hom comodules を構成。

PR #11894, 47af4c6 は family-invariant endomorphismsにより subgroup points を検出する criterionを追加しました。

Layer 3 API: Hopf-ideal inverse images

PR #11679, 4777b98 は Hopf-ideal inverse-image APIを整理・一般化しました。subgroup pullback / base change / kernel calculations の基礎です。

Layer 7: Chevalley theorem in line form

PR #11535, e328a49 は Chevalley theorem の「closed subgroup は適切な representation の line stabilizer」とする line-formを formalize しました。

これは homogeneous spaces、parabolics、Borel fixed-point route に直接使う general structure-theory inputです。
