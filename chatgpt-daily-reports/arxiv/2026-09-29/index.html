1. On the Kashaev--Luo--Vartanov Partition Function for Cusped 3-Manifolds: Asymptotics and a squared norm property

Author: Ka Ho Wong

Link: https://arxiv.org/abs/2609.33922

概要

Kashaev--Luo--Vartanov (KLV) partition function の漸近挙動と TQFT 的構造を解析する論文です。KLV partition function が angle structure 全体ではなく peripheral angular holonomies のみに依存することを示し、cusped 3-manifold の geometric triangulation が hyperbolic cone structure を実現するとき、指数的減衰率と 1-loop 項をそれぞれ volume と adjoint twisted Reidemeister torsion により記述します。

さらに admissible Neumann--Zagier data に付随する Reshetikhin--Turaev-type function を導入し、適切な normalization のもとで KLV partition function がその squared norm の weighted integral として表されることを示します。FAMED triangulations ではこの関数が Teichmüller TQFT に現れる Jones function と一致し、Turaev--Viro invariant と Reshetikhin--Turaev invariant の関係の noncompact analogue が得られます。

数学的関連

3-manifold quantum invariants、ideal triangulations、Neumann--Zagier data、hyperbolic volume、Reidemeister torsion、Teichmüller TQFT が一つの式の中で直接結び付く点が非常に強いです。特に

\[\text{KLV partition function} \quad\longleftrightarrow\quad \int \left|\text{RT-type function}\right|^2\]

という構造は、state-sum 型 invariant と RT 型 invariant の関係を noncompact quantum topology で理解する具体的なモデルになっています。量子不変量の asymptotic expansion と古典幾何の対応という観点からも直接的です。

2. Inequivalent modular tensor categories with identical \(S\), \(T\) and \(W\)

Authors: Ran Luo, Jiahua Tian

Link: https://arxiv.org/abs/2609.33231

概要

modular data \((S,T)\) と Whitehead-link matrix \(W\) を合わせれば modular tensor category が ribbon equivalence まで決まるか、という問題に否定的な答えを与えます。

素数 \(p\ge 5\) に対する \((\mathbb Z/p\mathbb Z)^3\) の Dijkgraaf--Witten modular categories の中に、braided equivalence では異なるにもかかわらず、同じ \((S,T,W)\) を持ち、さらに同一の simple objects の対応のもとで 2成分以下のすべての framed oriented links の Reshetikhin--Turaev invariants が一致する例を構成します。一方、適切な closed oriented 3-manifold 上の partition function はこれらを区別します。

数学的関連

これは「link invariants が modular category をどこまで検出できるか」という問題に非常に明確な境界を与えています。特に、2-component link までの RT invariants がすべて一致しても closed 3-manifold invariant では区別できるため、

\[\text{link data} \;\not\Rightarrow\; \text{full 3-dimensional TQFT data}\]

という現象を具体例で示しています。modular category、Dijkgraaf--Witten theory、RT invariant、3-manifold partition function の情報量を比較するうえで重要な結果です。

3. Relative dualizability and the cobordism hypothesis for defects

Author: William Stewart

Link: https://arxiv.org/abs/2609.32723

概要

fully local topological field theory における codimension-\(k\) defects の二つの記述を比較します。一方は cobordism hypothesis with singularities による dualizable \(k\)-morphisms としての記述、もう一方は source/target TFT の truncations 間の symmetric monoidal (op)lax natural transformations としての記述です。

主結果は、この二つが one-sided iterated adjunctibility という条件を介して一致することです。さらに higher Morita category に適用し、\(E_n\)-algebra 上の module の dualizability に関する reduction theorem を得ています。

数学的関連

TQFT に defect を入れたとき、幾何学的な defect data と higher categorical morphism data がどの条件で一致するかを明示しています。extended TQFT、higher Morita categories、\(E_n\)-algebras の間の対応を扱うため、3d/4d TQFT の boundary・defect 構造や higher categorical formulation を考える際の基礎的な結果です。

4. Lens Space Surgeries and the Bleiler-Litherland Conjecture

Author: Qilong Guo

Link: https://arxiv.org/abs/2609.31757

概要

Bleiler--Litherland conjecture、すなわち hyperbolic knot in \(S^3\) に対する nontrivial Dehn surgery で lens space が得られるなら、その lens space の order は少なくとも \(18\) である、という予想を証明します。

中心となる obstruction は、genus \(g\) の hyperbolic knot \(K\) が slope \(\pm(4g-2)\) の lens space surgery を持つなら、Alexander polynomial \(\Delta_K(t)\) が unit circle の外側に real root を持つという spectral statement です。証明には Floer-theoretic restrictions、Gabai の degeneracy-slope bound、essential laminations、Ni の monodromy fixed-point theorem などが組み合わされています。

数学的関連

lens spaces と knots の関係を Dehn surgery の方向から非常に具体的に制約する結果です。Alexander polynomial のスペクトル的性質が lens-space surgery を obstruct するという点で、3-manifold topology、fibered knots、monodromy、Floer theory が直接結び付きます。lens space と knot invariant の関係を理解するための構造的な結果として重要です。

5. Cyclotomic factors and irreducibility of the denominators of \(q\)-deformed rational numbers

Author: Kengo Miyamoto

Link: https://arxiv.org/abs/2609.33703

概要

\(q\)-deformed rational number \([r/s]_q\) の denominator \(S_{r/s}(q)\) に cyclotomic polynomial がいつ割り切れるかを決定します。

primitive \(d\)-th root of unity において \(q\)-deformed modular group が triangle group \((2,3,d)\) になることを用い、\(d\)-th cyclotomic polynomial が \(S_{r/s}(q)\) を割る rational numbers \(r/s\) を、\(\mathrm{PSL}(2,\mathbb Z)\) における translation \(z\mapsto z+d\) の normal closure の \(\infty\)-orbit として記述します。また特定の \(a\) と十分大きい \(n\) に対し、\(S_{a/n}(q)\) が cyclotomic factors を除いて irreducible であることを示します。

数学的関連

\(q\)-deformation、modular group、roots of unity、cyclotomic arithmetic が非常に直接的に交差する論文です。特に modular-group orbit が denominator の cyclotomic divisibility を完全に支配するという構造は、\(q\)-series の root-of-unity behavior や quantum modularity 周辺で現れる arithmetic phenomena と比較する価値があります。

6. Qin's quasimodularity conjecture for Hilbert schemes of points

Authors: Victor Alekseev, Avik Chakravarty, Daebeom Choi, Shengjing Xu

Link: https://arxiv.org/abs/2609.33884

概要

numerically trivial canonical class を持つ smooth projective complex surface \(X\) に対し、Hilbert schemes \(X^{[n]}\) 上の tautological bundles の Chern characters と total Chern class の intersection numbers から作られる reduced generating series が、予想された mixed-weight bound を持つ quasimodular form になるという Qin の予想を証明します。

証明では Nakajima operators の normally ordered products に対する Wick-theorem 型 trace formula を構成し、operator-valued currents と Carlsson--Okounkov operator の supertrace を quasi-elliptic functions と quasimodular function で表します。最終的に一般の generating series を計算する explicit algorithm も与えます。

数学的関連

Hilbert schemes、Heisenberg/Nakajima operator formalism、quasi-elliptic functions、quasimodular forms が統一的に現れます。quantum modular form そのものではありませんが、「幾何学的 generating function に modular/quasimodular structure が生じる仕組み」を表現論的 trace formula から説明する例として重要です。

7. Satellites and invariants of links

Author: Sergey A. Melikhov

Link: https://arxiv.org/abs/2609.33309

概要

link invariant \(v\) が cabling に対して

\[v(L')=(p_1\cdots p_m)^k v(L)\]

という scaling law を満たすとき cableable と呼び、そのような finite type invariant で pairwise linking numbers の関数ではないものが存在するか、という問題に肯定的に答えます。さらに cabling を arbitrary satellites に置き換えられることも示します。

主要な道具は Conway potential function の低次数係数の解析で、Milnor \(\bar\mu\)-invariants の modification を含む finite-type でない cableable invariants も議論します。

数学的関連

satellite operation の下で link invariants がどのように変換するかを体系的に扱っており、finite type invariants、Conway potential、Milnor invariants の関係が明示されます。knot/link operation と invariant の functorial な振る舞いという観点から、3-dimensional topology の不変量論に直接関係します。
