1. Cluster structures from Legendrian double twist knots: a comparative approach

Authors: James Hughes, Jiajie Ma

Link: https://arxiv.org/abs/2610.02086

概要

同じ smooth knot type を持つ異なる Legendrian knot に付随する cluster algebra を系統的に比較する。Double twist knot の族について、Legendrian representative の \(m\)-graded augmentation variety 上に cluster structure を構成し、異なる representatives から得られる cluster structures が互いに同値であることを示す。Maslov-\(m\) exact Lagrangian fillings を特徴付け、Catalan 数個の fillings を構成する。Maslov-\(0\) fillable representative が positive braid の \((-1)\)-framed closure と Legendrian isotopic であること、cabled twist knots から infinite-type の同値な cluster structures が得られることも示す。

数学的関連性

Cluster algebra と Legendrian/contact topology の接続を、cluster chart の存在だけでなく 異なる幾何的 presentation の比較と同値性として扱う点が重要である。Augmentation varieties、Lagrangian fillings、positive braids が同じ構造に現れるため、braid や symplectic geometry から得られる複数の cluster presentations がどの程度 canonical かを調べるモデルケースになる。

2. Mock Modularity, Resurgence, and Dual False Theta Functions

Author: Mrunmay Jagadale

Link: https://arxiv.org/abs/2610.00516

概要

負定値 plumbing から得られる3次元多様体の \(\hat Z\) invariant の orientation reversal を調べる。\(q\mapsto q^{-1}\) では通常の級数表示が破綻するため、Seifert manifolds と false theta functions を用いて dual false theta functions を構成する。Prescribed shadow を持つ mock modularity による特徴付けと、Borel--Mordell integrals・transseries を用いる resurgence による特徴付けが同値であることを証明する。Pell 方程式条件から新しい族を構成し、Zwegers の indefinite theta functions でも記述する。

数学的関連性

3次元多様体の量子不変量、false theta functions、mock modularity、resurgence を直接結び付ける。Orientation reversal に伴う \(q\mapsto q^{-1}\) を解析接続・Stokes phenomenon の問題として扱うため、量子不変量の radial limits や unit circle 上の境界値と強く関係する。Mock/indefinite theta completion と量子位相不変量の対応を解析的に理解する上で重要な例である。

3. Indefinite theta vectors and generalized Nahm sums of arbitrary rank

Authors: Dandan Chen, Siyu Yin

Link: https://arxiv.org/abs/2610.00967

概要

任意の rank \(r\ge 2\) の signed generalized Nahm sums に対して indefinite theta representation を構成する。適切な normalization と boundary correction の後、signature \((1,1)\) lattice に付随する \((2r-1)\) 成分 theta vector が現れる。Zwegers の理論から weight-one modular transformation law と明示的な finite sine \(S\)-matrix を求め、nonholomorphic correction とその antiholomorphic derivative も具体化する。さらに symmetrizable matrix families とその duals に対して product vectors を generalized Nahm sums の有限結合で表す。

数学的関連性

Nahm sums の modularity を低 rank の個別恒等式ではなく、任意 rank の vector-valued indefinite theta theory に組み込む点が強い。明示的な \(S\)-matrix、completion、shadow 型の微分が揃うため modularity failure を成分ごとに追跡できる。Symmetrizable matrices と duals が直接扱われ、Rogers--Ramanujan 型恒等式、Nahm sums、vector-valued modularity、quantum modular phenomena の比較にも有用である。

4. \(\mathrm{PGL}_2\) skein algebras of small surfaces

Authors: Cole Ellison, Vijay Higgins, Mark Sandey, Eden Sylvester

Link: https://arxiv.org/abs/2610.01075

概要

Closed torus と once-punctured torus の \(\mathrm{PGL}_2\) skein algebra に有限 presentation と明示的 basis を与える。Torus では Frohman--Gelca 型の product-to-sum formula を得て、basis の twist により structure constants が

\[\mathbb N[q,q^{-1}]\]

に入るようにできる。さらに Kauffman bracket skein algebra への自然な写像の kernel と、quantum parameter \(q\) の specialization に依存する center を計算する。

数学的関連性

Torus と once-punctured torus は skein algebra、character variety、mapping class group、quantum Teichmüller/cluster structures の関係を明示計算できる基本例である。Positive structure constants と specialization-dependent center は quantum cluster positivity や root-of-unity geometry と比較しやすい。Once-punctured torus における skein presentation と quantum cluster presentation の対応を検証する具体的な基礎データになる。

5. \(\mathrm{PGL}_2\) webs at roots of unity

Authors: Vijay Higgins, Bryan Silva, Amy Somers, David Stephens, Srijan Sundar, Parth Wokhlu

Link: https://arxiv.org/abs/2610.01881

概要

Surface 上の \(\mathrm{PGL}_2\) skein theory を roots of unity で研究する。\(\mathrm{PGL}_2\) 版 Chebyshev polynomials を構成して central elements を作り、3-punctured sphere と closed torus の Frobenius homomorphism を計算する。Closed torus では、\(q^2\) が偶数位数の root of unity のとき Frobenius homomorphism が injective でないことを示す。

数学的関連性

Root-of-unity specialization は generic skein algebra から有限次元表現・TQFT・量子不変量へ移る中心的操作である。Chebyshev/Frobenius 構造は skein algebra の classical shadow と character variety を結ぶ基本装置であり、偶数位数での非単射性は \(\mathrm{PGL}_2\) 固有の quantum geometry を示す。Quantum groups、skein theory、cluster quantization の比較に直接関係する。

6. Complete Factorial Asymptotics and Integrable Structure of Generalized Charlier Recurrence Coefficients

Author: Mahouton Norbert Hounkonnou

Link: https://arxiv.org/abs/2610.00396

概要

離散 weight

\[\rho_\mu(k)=\frac{\mu^k}{(k!)^2}\]

に付随する generalized Charlier polynomials の recurrence coefficients を解析する。変数変換

\[\beta_n-n=\sqrt{\mu}\,c_nc_{n+1},\qquad \gamma_n=\mu(1-c_n^2)\]

により positive sequence \((c_n)\) が discrete Painlevé II equation を満たすことを示し、その線形化を discrete Bessel equation と結び付ける。さらに Hankel determinant の logarithmic-gas representation から同じ factorial correction を導き、discrete Painlevé dynamics、Toda deformation、Hankel determinants を統一する。

数学的関連性

\(q\)-Painlevé そのものではないが、orthogonal-polynomial recurrence から discrete Painlevé equation が生じる典型的な integrable mechanism を精密に解析している。Painlevé dynamics、Toda flow、Hankel determinant、connection asymptotics の結合は、\(q\)-difference Painlevé systems の tau-functions や determinant formulas と比較する上で有用である。

7. Rectangular Cyclotomic Expansions of Colored HOMFLY-PT Polynomials

Authors: Honghuai Fang, Tian Zhou

Link: https://arxiv.org/abs/2610.00303

概要

任意の zero-framed knot の reduced colored HOMFLY-PT polynomial に対する rectangular cyclotomic expansion conjecture を証明する。また rectangular colors と非零 twist parameters に対して double-twist knots の明示公式を与える。各 knot に対して

\[\mathbb Z[A^{\pm1},q^{\pm1}]\]

係数の double Newton expansion を構成し、その係数が rectangular color の width と height に依存しないことを示す。証明には finite-rank representation symmetry、integral interpolation、Casimir operators を用いる。

数学的関連性

Cyclotomic expansion は colored Jones/HOMFLY 型量子不変量の integrality、root-of-unity specialization、Habiro 型 completion と密接に関係する。Rectangular colors に依存しない普遍係数の存在は knot invariant の安定な arithmetic data を抽出する。Double-twist knots の明示公式は root-of-unity limits や3次元量子不変量との接続、skein-theoretic 記述と quantum-group 記述の比較に有用である。

まとめ

Cluster algebra では Legendrian knot の augmentation variety 上の cluster structures を比較する直接的な論文がある。Quantum modular forms そのものの直接ヒットはないが、dual false theta functions を mock modularity と resurgence の両面から特徴付ける論文と、arbitrary-rank generalized Nahm sums を indefinite theta vectors に埋め込む論文が非常に近い。

Quantum topology 側では \(\hat Z\)、\(\mathrm{PGL}_2\) skein algebras/webs、colored HOMFLY-PT cyclotomic expansions がまとまって現れている。\(q\)-Painlevé の直接ヒットはないが、generalized Charlier recurrence coefficients から discrete Painlevé II、Toda deformation、Hankel determinant が同時に現れる論文が近い候補である。
