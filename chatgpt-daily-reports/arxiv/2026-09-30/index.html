1. Congruences for the Andrews--Uncu partition function \(\mathcal{EO}_u(n)\)

Authors: Nayandeep Deka Baruah, Hirakjyoti Das, Manjil P. Saikia, Abhishek Sarma

Link: https://arxiv.org/abs/2609.37920

概要

Andrews の partition function \(\mathcal{EO}(n)\) のうち、even parts に repetition を許さない部分を数える \(\mathcal{EO}_u(n)\) に対して、\(2\) の冪を法とする複数の合同式を証明します。さらに無限族の congruences と recurrence relation を与えます。

証明には elementary な generating-function manipulations、algorithmic methods、modular-form techniques が併用されています。したがって、単なる個別の partition congruence ではなく、partition generating function の arithmetic structure を modular forms によって制御するタイプの結果です。

数学的関連

\(q\)-series、partition identities、modular forms の交点にあるため、今日の新着の中では quantum modularity 周辺に最も近い論文です。特に

\[\text{partition generating function} \longrightarrow \text{modular-form structure} \longrightarrow \text{infinite congruence families}\]

という流れは、Rogers--Ramanujan 型恒等式や Nahm-sum 型 \(q\)-series の算術的性質と比較しやすい構造です。合同式の証明手法が、product formula を持つ \(q\)-series の modular arithmetic を調べる際にどこまで移植できるかが興味深い点です。

2. Idempotents in the Temperley-Lieb Monoid and Other Categories

Author: Louis H. Kauffman

Link: https://arxiv.org/abs/2609.34282

概要

identity morphism の factorization から生じる idempotents を、Temperley--Lieb monoid の planar diagrammatics を使って記述します。Temperley--Lieb monoid の idempotents と meanders の間の対応を解析し、同様の構造を Brauer monoid、tangle monoid、tangle category に拡張します。

中心的な視点は、代数的な idempotent condition を planar curves の組合せ論へ翻訳することです。これにより、factorization of identity と diagram composition の関係が非常に具体的になります。

数学的関連

Temperley--Lieb category は braid groups、Jones-type constructions、quantum \(\mathfrak{sl}_2\) representation theory、skein theory の基本的 diagram category です。ここで扱われる

\[\text{factorization of }1 \quad\leftrightarrow\quad \text{idempotent} \quad\leftrightarrow\quad \text{planar meander data}\]

という対応は、diagrammatic categories の内部構造を combinatorial geometry から理解する例です。

特に tangle category まで同じ機構を追っているため、braid/tangle operations を algebraic or categorical moduli と結び付ける場面で、どの構造が diagrammatics の段階ですでに決まっているかを見るためのよいモデルになります。

3. Structure and Representations of a Diagrammatic Non-Commutative Tangloid Algebra

Authors: Hadeel B. Albeladi, Sofia Lambropoulou

Link: https://arxiv.org/abs/2609.37524

概要

Turaev の knotoid theory に動機づけられた tangloid category から、non-commutative tangloid algebra \(\mathcal T_n\) と braidoid subalgebra \(\mathcal B_n\) を構成します。

unoriented welded tangleoid category から welded relation を外し、forbidden moves と追加 relations を組み込んだ category を出発点とします。さらに placeholder morphism を加えた extended tangloid category を導入し、その fixed \(n\)-box の endomorphism algebra を線形化して \(\mathcal T_n\) を定義します。

また trivial knot / knotoid components に対する reduction relations を加えた reduced tangloid algebra と、reflection・composition・closure を使う diagrammatic bilinear pairing を構成します。

数学的関連

braids、tangles、knotoids、diagram algebras の関係を一つの categorical algebra にまとめている点が重要です。braidoid が tangloid category の subcategory / subalgebra として自然に出るため、

\[\text{braid-like objects} \subset \text{tangle-like objects} \longrightarrow \text{endomorphism algebra}\]

という階層が明確です。

braid varieties や weave のように braid combinatorics から幾何・代数構造を作る枠組みと直接同じものではありませんが、「diagram operation を endomorphism algebra として組織化する」という設計原理は比較対象としてかなり近いです。

4. On the Hilbert polynomial of the linked projective space

Authors: Felipe De León, Eduardo Esteves, Eduardo Vital

Link: https://arxiv.org/abs/2609.37634

概要

linked projective spaces を、特定の quiver representations に対する 1-dimensional subspaces の quiver Grassmannians として扱います。これらは degenerations of linear series から自然に生じ、limit divisors を parameterize します。

主結果は、linked projective space が projective spaces の積における small diagonal と同じ multivariate Hilbert polynomial を持つことです。そのために、

  1. multiplicity-free strata をもつ simple normal-crossings schemes の Hilbert polynomial formula を与える、
  2. linked projective spaces が Mustafin varieties を用いた局所記述から normal-crossings であることを示す、
  3. components の intersections と simplex tiling の polytopes を対応させる、

という段階を踏みます。

数学的関連

quiver Grassmannians と degenerations of geometric moduli が明示的に結び付く論文です。quiver から得られる幾何空間について、

\[\text{quiver representation} \longrightarrow \text{quiver Grassmannian} \longrightarrow \text{normal-crossing degeneration} \longrightarrow \text{Hilbert polynomial}\]

という幾何的な辞書が得られています。

cluster geometry そのものではありませんが、quiver data から moduli を作り、その degeneration・stratification・intersection combinatorics を解析するという意味で、cluster varieties や flag-type moduli と近い問題設定です。

5. Six functor formalisms via internal higher algebra

Authors: Shachar Carmeli, Guy Kapon, Noam Nissan

Link: https://arxiv.org/abs/2609.37520

概要

six-functor formalism

\[D:\operatorname{Span}(C,E)\to\operatorname{Cat}\]

を \((\infty,2)\)-categorical な lax symmetric monoidal functor へ拡張します。\(D\)-proper morphisms と \(D\)-étale morphisms の classes を用い、Mann の conjecture を証明するとともに、Cnossen--Lenz--Linskens の結果の特殊例を一般化します。

証明のために、\(\infty\)-topos 内の local class \(\mathsf E\) に対する internal \(\mathsf E\)-monoidal categories と \(\mathsf E\)-operads の理論を発展させます。

数学的関連

extended TQFT や sheaf-theoretic constructions で頻出する「functoriality の複数方向」を higher categorical に統一する枠組みです。six operations を単に個別の adjunction としてではなく、\((\infty,2)\)-categorical span formalism の一部として組織化している点が核心です。

higher categories、TQFT、geometric representation theory の formalism を比較する際に、どの coherence が自動的に得られ、どこが additional structure なのかを整理する基盤として有用です。

6. On topologically transitive subsets of flag manifolds

Authors: Subhadip Dey, Sami Douba, Konstantinos Tsouvalas

Link: https://arxiv.org/abs/2609.37752

概要

higher-rank Lie groups の Anosov subgroups が flag manifolds 上で作用するとき、通常の Anosov limit set 以外の部分集合上で現れる topological dynamics を解析します。

strictly convex domain を dividing する projective transformation group が ellipsoid stabilizer と Zariski-dense に交わる場合、domain complement に dense orbit を持ち、domain に tangent な full projective flags の空間上で minimally acting することを示します。

また、partial flag manifold では Anosov でありながら、Furstenberg boundary の Benoist--Guivarc'h limit set から Anosov limit set への equivariant projection が fibration にならない Zariski-dense examples も構成します。

数学的関連

flag manifolds、higher-rank groups、Anosov representations、homogeneous dynamics の接点にあります。特に full flags と partial flags の間の projection が topologically 単純でない現象を具体化しており、

\[G/P_{\min}\longrightarrow G/P\]

のような flag projection が dynamics をどの程度保持するかという問題を扱っています。

flag configurations や flag moduli を幾何的に用いる場面では、algebraic quotient / projection と dynamical boundary data の違いを理解するための有用な比較対象です。

7. Characteristic-free Knörrer periodicity

Author: Graham J. Leuschke

Link: https://arxiv.org/abs/2609.37839

概要

complete hypersurface ring

\[R=S/(f)\]

とその hyperbolic extension

\[A=S[\![u,v]\!]/(f+uv)\]

に対して、Knörrer functor が maximal Cohen--Macaulay modules の stable categories の equivalence

\[\operatorname{MCM}(R)\simeq \operatorname{MCM}(A)\]

を与えることを、residue characteristic に仮定を置かず証明します。isolated singularity assumption も不要で、\(S\) が field を含む必要もありません。

一方、

\[R^{\sharp\sharp}=S[\![z,w]\!]/(f+z^2+w^2)\]

による iterated double branched cover は characteristic \(2\) では同じ periodicity を持たないことを明確にします。

数学的関連

stable categories、matrix-factorization 型現象、hypersurface singularities と branched-cover constructions の関係を characteristic-free に整理した結果です。

特に \(f+uv\) による hyperbolic stabilization と \(f+z^2+w^2\) による iterated double branched cover の差が characteristic \(2\) で可視化されるため、「branched cover が invariant/category をどのように変えるか」という問題の代数幾何版として非常に明瞭です。
