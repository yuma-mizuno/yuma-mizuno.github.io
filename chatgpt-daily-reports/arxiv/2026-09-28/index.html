1. Quantum Laurent positivity in rank three

Author: Qiyue Tang

Link: https://arxiv.org/abs/2609.30387

概要

Skew-symmetrizable な rank 3 quantum cluster algebra に対して Laurent positivity を証明しています。任意の integral compatible quantization と invertible frozen variables を許す一般性で、証明には companion manuscript の mutation-acyclic positivity を用います。

関連性

今日の第 1 優先テーマへの最も直接的な論文です。特に skew-symmetrizable、したがって non-simply-laced な quantum cluster data まで含む点が重要です。Rank 3 で量子 Laurent positivity がどこまで一般に成立するかを明確にしており、symmetrizable cluster structures や quantum cluster algebra の positivity を考えるうえで直接関連します。

2. Quasi-equivalence of relabeled positroid cluster structures

Author: Yilin Wu

Link: https://arxiv.org/abs/2609.30637

概要

Admissibly relabeled plabic graphs から得られる positroid cluster structures の quasi-equivalence に関する Fraser--Sherman-Bennett conjecture を証明しています。Boundary necklace から tilting module を構成して Frobenius categorification を与え、rank-one modules の localized characters を Plücker coordinates と同定します。さらに derived equivalence から relative index lattices の unimodular transformation を得て、full extended exchange matrices が対応することを示します。

関連性

Positroid、plabic graph、Plücker coordinate、cluster-tilting、exchange matrix を直接扱う第 1 優先テーマの論文です。異なる combinatorial presentations が同じ cluster geometry を与えることを categorical/derived な方法で証明しており、braid varieties や weave に由来する複数の cluster presentations を比較する際のモデルケースとしても興味深いです。

3. On the Relation Between Non-Semisimple TQFTs

Author: Marco De Renzi

Link: https://arxiv.org/abs/2609.31449

概要

Not necessarily semisimple な modular category \(\mathcal C\) に対し、adjoint end \(\mathcal E\) から得られる Kerler--Lyubashenko TQFT \(J_{\mathcal E}\) と、projective objects の ideal \(\mathrm{Proj}(\mathcal C)\) 上の modified trace を用いる renormalized TQFT \(V_{\mathcal E}\) の関係を整理しています。

主結果は、両者を同時に含む 3-dimensional extended TQFT \(\widehat{\mathbf A}_{\mathcal E}\) の構成です。これは admissible 3-dimensional cobordisms の 2-category から finitely complete linear categories の 2-category への 2-functor で、surface に対する従来の admissibility 条件を外すことで、circle category が projective ideal ではなく \(\mathcal C\) 全体と同値になります。

関連性

第 3 優先テーマに直接近い論文です。個別の WRT 値の計算ではありませんが、3-manifold quantum invariants を生成する TQFT の categorical structure を直接扱います。Boundary data、gluing、modified trace、non-semisimple quantum topology を理解するうえで重要です。

4. Planar Contact Structures with Calabi-Yau Fillings and Topological Quantum Computation

Author: Atsuhide Mori

Link: https://arxiv.org/abs/2609.30406

概要

Disk の branched cover を通じて braid を lift して得られる planar open books、contact 3-manifolds、Stein fillings と、Ising representation による quantum operations の関係を研究しています。Calabi--Yau Stein filling の criterion を与え、固定 monodromy の positive factorizations の中で CY factorization が minimal length を持つことを示します。

さらに admissible cuts による subopenbooks への分解を用い、CY condition が局所的に判定できることを示します。低い covering degree では state space の tensor-product decomposition と monodromy の関係も具体化されます。

関連性

Quantum invariant そのものではありませんが、braids、branched covers、contact 3-manifolds、mapping-class-type data、quantum representations が直接結び付いています。Braid geometry と 3-dimensional topology の接点として関連性が高い候補です。

5. Categorical spin-networks: state-sum invariants of 4-manifolds from higher-gauge theory

Authors: Hank Chen, Zhian Jia, Ran Luo, Wei Cui

Link: https://arxiv.org/abs/2609.31365

概要

Pivotal fusion 2-category を入力として \((3+1)\)-dimensional TQFT とその lattice realization を構成します。Triangulated 4-manifold に categorical data を配置し、4-simplex amplitude を計算する \(20j\)-symbol formalism を導入し、4-dimensional Pachner moves の下で state sum が不変であることを検証します。

また、その state-sum invariant を実現する 3-dimensional Levin--Wen-type lattice Hamiltonian を明示的に構成します。著者らはこれを Turaev--Viro invariant の spin-network construction の higher-dimensional analogue と位置付けています。

関連性

3 次元量子不変量より 1 次元高い理論ですが、Crane--Yetter 型 TQFT や higher gauge theory とかなり直接的に接続します。Fusion category から Turaev--Viro 3d state sum を作る構造を fusion 2-category と 4d state sum へ持ち上げる点が核心で、4d TQFT と 3d boundary/lattice theory の関係を考えるうえで有用です。
