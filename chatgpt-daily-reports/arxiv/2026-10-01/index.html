今日の新着では cluster algebra への直接ヒットが複数ある。一方、quantum modular form(s)、3次元多様体の quantum invariant、\(q\)-Painlevé equation を直接主題とする論文は確認できなかった。以下では cluster algebra を最優先し、その周辺として modular quantum dilogarithm、Coulomb branch、3次元トポロジーを選ぶ。

1. Grassmannian tree webs and cluster variables

Authors: Jian-Rong Li, Chenglu Wang, Lauren Williams

Link: https://arxiv.org/abs/2609.38398

概要

Grassmannian の斉次座標環の cluster algebra について、web invariant と cluster variable の対応を研究する。\(\operatorname{Gr}(3,n)\) で planar tree \(\mathrm{SL}_3\)-web が cluster または frozen variable を与える既知結果に新しい証明を与え、さらに \(\operatorname{Gr}(4,n)\) へ拡張して planar tree \(\mathrm{SL}_4\)-web の invariant も cluster または frozen variable になることを示す。証明には cluster quasihomomorphisms と新しい 6-leg pattern map を用いる。

数学的関連

cluster algebra への直接ヒットである。tensor diagram / planar web から cluster variables を認識し、Plücker geometry、web bases、canonical-basis 的構造を結ぶ。\(k=4\) への拡張は web combinatorics が複雑になる中で planar tree 条件が cluster variable を保証する強い幾何的判定を与える。quasihomomorphism による移送は異なる seed や combinatorial presentation の比較にも有用なモデルになる。

2. \(K_{\mathfrak q}\)-algebras

Author: Davide Gaiotto

Link: https://arxiv.org/abs/2609.38702

概要

4次元 \(\mathcal N=2\) supersymmetric quantum field theory の rotation-equivariant BPS line defects の fusion algebra を抽象化する \(K_{\mathfrak q}\)-algebra を提案し、Seiberg--Witten 型 RG flow の代数的定式化も与える。cluster algebras、\(K\)-theoretic Coulomb branch algebras、skein algebras、quantum groups を同時に含む枠組みを目指している。

数学的関連

cluster algebra と skein algebra、quantum group、Coulomb branch algebra を共通の公理的構造で結び付ける点が重要である。surface cluster algebra と skein quantization、BPS quiver、line-defect fusion の関係を整理する言語になり得る。RG flow を組み込むことで cluster mutation 的な局所変換と wall-crossing 型現象の比較も可能になる。

3. The twisted convolution identity and ghost \(r\)-SICs from finite quantum dilogarithms

Authors: Marcus Appleby, Steven T. Flammia, Gene S. Kopp

Link: https://arxiv.org/abs/2609.39192

概要

modular quantum dilogarithm の実二次体特殊値に対する finite pentagon relation を用い、twisted convolution identity を rank-\(r\) admissible tuples へ拡張する。modular quantum dilogarithm と Shintani--Faddeev modular cocycle の明示的な辞書を与え、条件

\[r<\frac{d-1}{2}, \qquad \frac{d^2-1}{r(d-r)}\in\mathbb Z\]

の下で \(\mathbb C^d\) 内の ghost \(r\)-SICs の存在を証明する。Stark conjecture の下では Hermitian \(r\)-SICs の Galois conjugates と解釈される。

数学的関連

quantum modular form 自体ではないが、modular quantum dilogarithm、実二次体、modular cocycle、pentagon identity を直接結ぶため quantum modularity に非常に近い。pentagon relation は量子 cluster mutation でも中心的であり、real-quadratic arithmetic と cluster-theoretic quantum dilogarithm の接点を具体的に追える。

4. Duality functors for Coulomb branches I

Authors: Sabin Cautis, Eric Vasserot

Link: https://arxiv.org/abs/2609.39122

概要

有限型 quiver に対し、affine quiver Hecke algebra の有限次元 modules から Coulomb branch に付随する Koszul-perverse coherent sheaves への exact functor を構成する。この functor は simple object を simple object または zero に送り、simples に関してほぼ essentially surjective である。その帰結として simple Koszul-perverse sheaves が dual canonical basis を categorify する。

数学的関連

quiver representation theory、canonical basis、Coulomb branch geometry を直接結ぶ categorical bridge である。cluster algebra 周辺では cluster monomials、dual canonical bases、theta bases の比較が基本問題であり、別の幾何 realization から dual canonical basis が現れることは重要である。quiver combinatorics が Coulomb branch geometry へ移るとき basis data がどのように保存されるかを具体化する結果として読める。

5. Lens space surgeries on knots of small genus

Authors: Misha Schmalian, Steven Sivek

Link: https://arxiv.org/abs/2609.39260

概要

genus が高々 \(5\) の hyperbolic knot について lens space surgery を分類し、\((-2,3,7)\) pretzel knot が唯一の例であることを証明する。主要な入力として、genus-\(g\) hyperbolic knot が slope \(>4g-3\) の elliptic surgery を持つ場合に monodromy の invariant foliations が orientable で、その orientation が monodromy により反転されることを示す。その結果、dilatation の負値が Alexander polynomial の root になる。既知結果と合わせて genus \(\leq 5\) で Berge conjecture を確認する。

数学的関連

3次元多様体の quantum invariant を直接扱う論文ではないが、lens spaces と Dehn surgery の強い rigidity を与える。lens spaces は WRT 型量子不変量の基本例であり、surgery presentation は量子不変量の構成と直結する。量子不変量が Dehn filling の幾何的制約をどの程度検出できるかを考える際の topology-side benchmark になる。

まとめ

今日の最も直接的なテーマ一致は、cluster algebra では Grassmannian tree webs and cluster variables と \(K_{\mathfrak q}\)-algebras、quantum modularity 周辺では finite quantum dilogarithms の論文である。3次元多様体の quantum invariant と \(q\)-Painlevé equation には直接ヒットはなかった。
